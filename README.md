# DeepReader 📚

Uma solução moderna e independente para curadoria e leitura de artigos, focada em simplicidade e privacidade.

## 🚀 Funcionalidades
- **Web Reader**: Captura e limpa links removendo anúncios e trackers.
- **Browser Extension**: Captura conteúdo diretamente da aba ativa (útil para sites logados).
- **Modos de Leitura**: Temas claro, escuro e sépia.
- **Exportação**: Geração de PDFs limpos para leitura offline.

## 🛠️ Tecnologias
- HTML5, Tailwind CSS
- [Readability.js](https://github.com/mozilla/readability) (Mozilla)
- Chrome Extension API V3
